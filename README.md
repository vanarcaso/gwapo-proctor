## Project Description

The Personal Task Manager is a Laravel-based system that allows users to create, view, edit, delete, and update the status of tasks.

Each task contains a task name, description, status, and due date.

## Features

- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Task Status
  - Pending
  - Completed

## Technologies Used

- Laravel
- PHP
- MySQL
- Blade
- HTML
- CSS

## Laravel Structure

The project follows the Laravel flow:

Routes → Controller → Model → Database → Blade

## Database Fields

The `tasks` table contains:

- `id` – Task ID
- `task_name` – Name of the task
- `description` – Task details
- `status` – Pending or Completed
- `due_date` – Task deadline
