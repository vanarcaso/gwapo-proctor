## Project Description

The Personal Task Manager is a Laravel-based system that allows users to create and manage personal tasks.

Each task contains a task name, description, status, and due date.

The project follows the Laravel flow:

**Routes → Controller → Model → Database → Blade**

## Features

- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Status
  - Pending
  - Completed

The task name and due date are required.

The description is optional.

The status can only be:

- Pending
- Completed
